# David Bellini's Transcriptomics Scripts
Hello, welcome to my repository. Here you will find a couple of the scripts I wrote during my PhD.
Most of them are involved in the custom MATQ single cell processing I did for the locust projects. 
The original sc_preprocess_fuzzy.py was written for our dT chemistry, the other one for our 
total RNA chemistry (using MALBAC primers).
I try to keep this updated to the latest central version but I often make changes on the fly depending
on any unique properties of the current experiment I'm working on.
